# Инструкция по использованию PcStorc

PcStorc — локальная Windows-программа для учета комплектующих, резервов, сборок и продаж компьютеров.

## 1. Скачать программу

Откройте страницу последней сборки:

https://github.com/Amatory6644/PcStorc/releases/tag/latest-build

Там доступны:

- `PcStorc.exe` — готовая программа для Windows;
- `PcStorc-windows.zip` — архив с готовой Windows-версией;
- `PcStorc-source.zip` — исходный код.

Для обычной работы достаточно скачать `PcStorc.exe`.

## 2. Первый запуск

1. Скачайте `PcStorc.exe`.
2. Положите файл в удобную папку, например `C:\PcStorc\`.
3. Запустите `PcStorc.exe` двойным кликом.
4. При первом запуске программа автоматически создаст локальную базу данных.

Основная база хранится отдельно от EXE:

```text
%LOCALAPPDATA%\PcStorc\pcstorc.db
```

Поэтому замена `PcStorc.exe` на новую версию не удаляет склад, сборки и продажи.

Если Windows SmartScreen предупредит о неизвестном издателе, это связано с тем, что EXE пока не подписан коммерческим сертификатом. Если файл скачан из этого репозитория, можно открыть `Подробнее` и выбрать `Выполнить в любом случае`.

## 3. Вкладка «Склад»

Здесь хранится список всех комплектующих.

Для каждой позиции отображаются:

- категория;
- модель;
- физическое наличие;
- количество в резерве;
- свободный остаток;
- уровень запаса;
- закупочная цена;
- поставщик;
- срок доставки;
- рекомендация по заказу.

### Добавить комплектующую

Нажмите `+ Позиция` и заполните данные.

Пример:

```text
Категория: Видеокарта
Модель: RTX 5060 8GB
Количество: 3
Закупочная цена: 28500
Поставщик: DNS
Доставка: 1 день
```

### Приход товара

1. Выберите позицию в таблице.
2. Нажмите `Приход`.
3. Укажите количество поступивших деталей.
4. Укажите фактическую цену этой закупки.
5. При необходимости измените поставщика.

Количество увеличится, а новая закупочная цена сохранится для позиции.

### Корректировка остатка

Если фактическое количество отличается от программы:

1. выберите позицию;
2. нажмите `Корректировать остаток`;
3. введите реальное физическое количество.

Используйте это для инвентаризации, а не для обычной продажи.

## 4. Зеленый, желтый и красный уровни

PcStorc показывает состояние запаса цветом:

- зеленый — запас нормальный;
- желтый — стоит готовиться к закупке;
- красный — комплектующая заканчивается или уже закончилась.

При принятии решения также учитывайте срок доставки. Детали с AliExpress, которые едут 10+ дней, имеет смысл заказывать раньше, чем детали с доставкой за один день.

## 5. Что значит «В наличии», «В резерве» и «Свободно»

Пример:

```text
В наличии: 5
В резерве: 3
Свободно: 2
```

Это означает, что физически лежит 5 деталей, но 3 уже обещаны под будущие сборки. Для новых сборок реально доступны только 2.

## 6. Вкладка «Сборки и продажи»

Здесь создаются будущие и проданные компьютеры.

Основные статусы:

- `Черновик` — сборка создана, но детали еще не зарезервированы;
- `В резерве` — комплектующие закреплены за этой сборкой;
- `Продано` — комплектующие списаны со склада;
- `Отменено` — резерв снят.

## 7. Создать сборку вручную

1. Нажмите `Новая сборка`.
2. Добавьте нужные позиции со склада.
3. Для каждой позиции укажите количество.
4. При необходимости вручную укажите закупочную цену именно для этой сборки.
5. Укажите клиента или описание.
6. Создайте сборку в резерве.

После резервирования свободный остаток соответствующих комплектующих уменьшится.

## 8. Быстрый ввод готового конфига

Если вам прислали конфигурацию текстом, нажмите `Быстрый конфиг` и вставьте список, например:

```text
Ryzen 7 9700X
MSI B650M-P
DDR5 32GB
RTX 5060 8GB
SSD 1TB M2
PowerCase 700W
XASTRA A305M
```

PcStorc попробует найти соответствующие модели на складе.

Перед созданием резерва программа покажет, что удалось сопоставить, а что не найдено.

Важно: сначала добавьте реальные модели комплектующих на вкладке `Склад`, иначе программе не с чем будет сопоставлять текст.

## 9. Продажа компьютера

Когда компьютер собран и реально продается:

1. выберите нужную сборку;
2. нажмите `Продать`;
3. введите фактическую цену продажи;
4. подтвердите операцию.

PcStorc автоматически:

- снимет резерв;
- спишет использованные комплектующие с физического наличия;
- сохранит себестоимость;
- сохранит цену продажи;
- рассчитает прибыль;
- запишет движение в историю.

Пример:

```text
Себестоимость: 78 377 ₽
Цена продажи: 95 000 ₽
Прибыль: 16 623 ₽
```

## 10. Если сборка отменена

Выберите резервированную сборку и нажмите `Отменить`.

Комплектующие снова станут свободными и смогут использоваться в других сборках.

## 11. Резервные копии

Откройте вкладку `Резервные копии`.

По умолчанию резервные копии сохраняются в:

```text
Документы\PcStorc Backups
```

Внутри ZIP-копии находятся:

- `pcstorc.db` — полная база программы;
- `inventory.csv` — склад;
- `builds.csv` — сборки и продажи;
- `build_items.csv` — состав сборок;
- `movements.csv` — история движений;
- `backup_info.json` — информация о резервной копии.

CSV можно открыть в Excel даже если сама программа не запускается.

### Сделать резервную копию сейчас

Нажмите `Создать копию сейчас`.

Рекомендуется сделать такую копию сразу после первого заполнения склада и перед крупными изменениями.

### Автоматическая ежедневная копия

1. Укажите папку для резервных копий.
2. Укажите время, например `21:00`.
3. Нажмите `Сохранить настройки`.
4. Нажмите `Установить задачу Windows`.

После этого Windows будет запускать резервное копирование по расписанию.

Для большей надежности можно выбрать папку внутри OneDrive, Google Drive, Яндекс Диска или другого синхронизируемого каталога.

## 12. Восстановление после сбоя

Если база испортилась или данные были случайно изменены:

1. закройте лишние экземпляры PcStorc;
2. откройте PcStorc;
3. перейдите в `Резервные копии`;
4. нажмите `Восстановить из ZIP`;
5. выберите нужный файл `PcStorc_backup_....zip`;
6. подтвердите восстановление.

После восстановления проверьте склад и последние сборки.

## 13. Обновление PcStorc

Новая готовая версия всегда публикуется здесь:

https://github.com/Amatory6644/PcStorc/releases/tag/latest-build

Чтобы обновиться:

1. желательно сделать резервную копию;
2. закройте PcStorc;
3. скачайте новый `PcStorc.exe`;
4. замените старый EXE новым;
5. запустите программу.

База остается в `%LOCALAPPDATA%\PcStorc\`, поэтому обычная замена EXE не должна удалять данные.

## 14. Рекомендуемый ежедневный порядок работы

1. Пришел товар → оформить `Приход`.
2. Получили будущий конфиг → создать сборку и поставить детали в резерв.
3. Сборка отменилась → снять резерв.
4. Компьютер продан → нажать `Продать` и указать цену продажи.
5. Если фактический склад расходится с программой → провести инвентаризационную корректировку.
6. В конце дня убедиться, что создана резервная копия.

## 15. Чего не стоит делать

- Не удаляйте вручную файл `pcstorc.db`, если нет резервной копии.
- Не редактируйте SQLite-базу сторонними программами во время работы PcStorc.
- Не заменяйте резервную копию единственным экземпляром — лучше хранить несколько предыдущих копий.
- Не оформляйте продажу через ручную корректировку склада: используйте сборку и кнопку `Продать`, иначе потеряется история и расчет прибыли.

## 16. Если что-то работает неправильно

Перед исправлением желательно сохранить:

- скриншот ошибки;
- что именно нажимали перед ошибкой;
- резервную копию базы;
- версию или дату скачанного EXE.

Исходный код проекта и история изменений находятся в этом репозитории:

https://github.com/Amatory6644/PcStorc
