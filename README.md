# PcStorc

**PcStorc** — локальная Windows-программа для учета комплектующих при сборке и продаже компьютеров.

Первая версия рассчитана на **одного пользователя и один компьютер**. Сервер и интернет для работы не нужны. Данные хранятся в локальной SQLite-базе.

## Что уже умеет

### Склад
- категории комплектующих;
- модель;
- фактическое наличие;
- количество в резерве;
- свободный остаток;
- последняя закупочная цена;
- поставщик;
- срок доставки;
- желтый и красный пороги;
- автоматическая подсветка зеленый / желтый / красный;
- приход товара с отдельной закупочной ценой;
- ручная инвентаризационная корректировка;
- история всех движений.

### Сборки и резервы
- создание новой конфигурации ПК;
- каждая строка конфигурации привязана к реальной позиции склада;
- себестоимость фиксируется по каждой комплектующей и может быть введена вручную;
- сборку можно сразу поставить в резерв;
- зарезервированные детали перестают считаться свободными;
- программа не дает зарезервировать больше, чем есть в наличии;
- есть черновики, резервы, продажи и отмененные сборки.

### Быстрый ввод конфигурации
Можно вставить текст вроде:

```text
Ryzen 7 9700X
MSI B650M-P
CUSU DDR5 32GB
RTX 5060 8GB
CUSU 1TB M2
PowerCase 700W
XASTRA A305M
```

PcStorc попробует сопоставить каждую строку с уже заведенными моделями на складе и добавить найденные позиции в сборку.

### Продажи и прибыль
При продаже резервированной сборки PcStorc:
1. списывает нужное количество комплектующих со склада;
2. сохраняет историю списания;
3. фиксирует цену продажи;
4. сохраняет себестоимость;
5. считает прибыль.

### Резервные копии
Каждая резервная копия — ZIP-файл, внутри которого находятся:
- `pcstorc.db` — полная база;
- `inventory.csv` — склад;
- `builds.csv` — сборки и продажи;
- `build_items.csv` — состав сборок;
- `movements.csv` — история движений;
- `backup_info.json` — информация о копии.

CSV-файлы можно открыть обычным Excel даже без PcStorc.

По умолчанию:
- ежедневная копия: **21:00**;
- копия при закрытии программы: включена;
- хранится 30 последних ZIP-копий;
- папка: `Документы\PcStorc Backups`.

В интерфейсе можно изменить папку, время и число хранимых копий.

На Windows кнопка **«Установить задачу Windows»** регистрирует PcStorc в Планировщике заданий. После этого команда `PcStorc.exe --backup` выполняется каждый день в выбранное время, даже если интерфейс PcStorc не открыт.

## Где хранится основная база

На Windows:

```text
%LOCALAPPDATA%\PcStorc\pcstorc.db
```

Базу данных не нужно класть рядом с EXE. Поэтому обновление или замена программы не удаляет учетные данные.

## Запуск из исходников

Нужен Python 3.12+.

```powershell
py -3 main.py
```

Или запустите `run_from_source.bat`.

В runtime-зависимостях сторонних библиотек нет: интерфейс использует Tkinter, база — встроенный `sqlite3`.

## Сборка Windows EXE

Самый простой вариант — GitHub Actions. При каждом push в `main` workflow `.github/workflows/build-windows.yml`:
1. запускает тесты;
2. собирает `PcStorc.exe` через PyInstaller;
3. прикладывает EXE как artifact `PcStorc-windows`.

Локально на Windows можно выполнить:

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

После сборки:

```text
dist\PcStorc.exe
```

## Тесты

```powershell
py -3 -m unittest discover -s tests -v
```

Сейчас покрыты базовые сценарии:
- приход и корректировка остатков;
- запрет резервировать отсутствующий товар;
- резерв → продажа → списание;
- себестоимость и прибыль;
- быстрый поиск моделей в вставленном конфиге;
- создание резервной копии с БД и CSV.
